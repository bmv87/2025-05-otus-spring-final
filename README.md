# Итоговый проект по курсу "Разработчик на Spring Framework"
Тема "Электронная библиотека"

Проект состоит из:
    Api по работе с книгами
    s3(minio) файлового хранилища для загрузки файлов книг и изображений
    keycloak - сервиса для аутентификации
    ui(vue) - небольшое приложение для демонстрации работы api

Использованные технологии:
    базы данных Postgres и H2(тесты) + flyway/jpa
    Spring mvc
    Spring Security (oauth2 resource server со своей авторизацией, на основе ролей из бд)
    Spring Actuator
 

Вся инфраструктура собрана на образах docker (папка environment) с использованием переменных окружения

Настроено логирование и локализация ошибок, передаваемых фронту.

Коротко о функционале:
    Пользователи имеют роли ADMIN READER и анонимные
        У ADMIN есть возможность 
            - создавать/редактировать/удалять книги и создавать/удалять ссылки на файлы (в том числе загружать сами файлы)
            - просматривать расширенный список книг (отображается поле createdBy)
            - просматривать расширенный список разделов и авторов (отображается поле createdBy)
        У READER есть возможность просмотреть 
            - обычный список книг
            - список разделов и авторов для выбора в фильтрах
            - картинки, прикрепленные к книге
            - ссылки на файлы и скачать файлы книг

        У анонимного пользователя есть возможность просмотреть 
            - обычный список книг
            - список разделов и авторов для выбора в фильтрах
            - картинки, прикрепленные к книге
        Ссылки на файлы анонимный пользователь просмотреть не может
